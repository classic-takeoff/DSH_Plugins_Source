# Balance Badge

在 DeepSeek Harness 里放一张角色立绘卡片：余额显示在角色左上角的对话框里（「余额：12.34」），人物可以拖动、可以缩放，松手后自动吸附到最近的窗口边缘。

- **余额在对话框里**：`余额：` 加两位小数，无货币符号、无千分位。读取中显示 `余额：···`，失败或未登录显示 `余额：--`。
- **对话框不跟着缩**：人物和对话框是两层——缩放只改变人物大小，对话框和文字保持固定尺寸（文字 9–13px，按数字长度自适应），缩到很小也读得清。
- **对话框在人物左上方**：它挂在人物左上角外侧，不遮挡人物；吸附到窗口左边或顶边时，气泡所在的空间会被算进去，所以对话框不会被窗口边缘裁掉。
- **拖动 + 吸附**：按住人物或对话框拖动，松手后自动贴到最近的左 / 右 / 上 / 下边缘。
- **手动调大小**：悬停卡片，拖动右下角的 `⤡` 手柄缩放；也可以在卡片上按住 `Ctrl` 滚轮缩放。人物宽度范围 120–680px（受限屏宽），对话框固定 92×75px。
- **点击刷新**：不拖动的单击会立即重新读取余额（键盘 Enter / 空格同样可用）。
- **自动更新**：每 60 秒读取一次余额。
- **记忆**：位置和大小存在本地（`dsh-balance-badge/position`），下次打开保持。
- **自适应**：窗口缩放时卡片会被夹在可视区域内。

余额来自 DSH 的 `account.getBalance` Remote（与「设置 → 账户」同一个数据源），只显示，不做任何修改。

## 安装

插件通过插件市场索引安装：

```text
https://classic-takeoff.github.io/DSH_Plugins_Source/index.json
```

安装后无需配置，卡片默认贴在窗口右下角。

## 实现

- `lib/index.js`：Host 半侧，空 `apply`，只保证插件行可挂载。
- `lib/client.js`：浏览器半侧，向 `shell.overlay` 槽注册固定定位的角色卡片。人物与对话框是两张 WebP（data URL 内嵌，不请求网络）：人物层随缩放变化，对话框层保持固定像素尺寸并锚定在人物头部左侧。
- `icon.webp`：插件管理器里显示的图标。
